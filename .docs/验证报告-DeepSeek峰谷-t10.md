## 6. ADVISORY（唯一遗留项，按 captain 裁决 D1 不作 blocker）

- **事实**：flash 新价的唯一载体是 DeepSeek 开放平台 2026-09-09 调价公告的**逐字转载**（大众网/界面新闻含平台公告截图、IT之家含官方 API 用户通知邮件，另 10+ 家同稿源）。一次性一手页面不可得：`platform.deepseek.com/announcements` 为登录态 SPA（未登录仅返回空壳）、`/api/v0/announcements` → HTTP 404、`api-docs.deepseek.com/zh-cn/updates` 最新条目 2026-08-21、`sitemap.xml` 新闻止于 `news260821`；官方定价页（中/英文）截至我 13:12 复核仍为调价前价。
- **影响**：本项目的 flash 价属「公告口径正确、一级页面尚未同步」状态；若公告为误传（我认为可能性低：多源一致、含官方邮件截图、且「调整前」列与官方页逐值吻合），界面显示的 flash 价会低于实际计费价。
- **已采取的处置**：用户可见界面 + 弹窗文档 + 代码注释三处均如实披露来源、生效时点、证据等级与「定价页尚未同步」。
- **可行替代路径（供用户/后续复核）**：① 用户在**登录态**开放平台人工查看 `announcements` 公告原文并截图留档；② 待官方定价页/更新日志同步后，按新快照复核并把注释中的「13:04–13:06」复核时刻更新为新证据时刻；③ 若 2026-09-14 12:00 `deepseek-v4-pro` 路由到 V4.1 Flash 的计费口径变化，按 `registry.ts:44` 的 TODO 与 `deepseek.md:54` 复核 pro 行。
