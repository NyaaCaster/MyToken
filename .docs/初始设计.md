# MyToken 初始设计

> 本文件记录用户原始需求与设计意图（设计基线），供后续开发与交接引用。

## 一、项目定位

**MyToken** 是一个**汇总查询个人各 API 供应商平台个人额度**的网页应用：把用户分散在多家平台的余额/额度/订阅用量聚合到一个竖版瀑布式页面，一目了然。

- 仓库：https://github.com/NyaaCaster/MyToken.git
- 遵循 `NYAACASTER-DEV-GUIDE.md` 开发。

## 二、设计要点

### 布局
- 竖版瀑布式**纵向布局**；每供应商 = 一个模块，自上而下排列：
  `QinyAPI → DeepSeek → OpenCode-Go → 硅基流动 → 各种 Coding Plan → 后续追加`。
- 以下模块标题带有可**新开页面**的 URL：
  - QinyAPI：https://love.qinyan.icu/register?aff=btB0
  - OpenCode-Go：https://opencode.ai/go?ref=TZCVZ4X21V
  - 硅基流动：https://cloud.siliconflow.cn/i/KJ0qgMuR

### 每模块交互
- 仅两个用户操作：**鉴权密钥填入栏** + **启用开关**。
- 密钥填入后**隐藏显示**（防抓取/泄漏）。
- 密钥输入栏后带 **? 图标按钮**：点击浮窗展示该供应商鉴权密钥获取说明文档（**每供应商一份独立 md**，前端正确渲染 md）。
- 开关开启时**即时鉴权**：鉴权不成功则开关无法开启；开关不开启则该模块内容收起（减少前端渲染压力）。

### 页眉
- 左上角 = 项目 icon + 名称 **MyToken**，点击跳转本仓库。
- 右上角 = 功能图标按钮区，**由右向左**排列：主题风格（浅色/暗色/跟随系统，默认跟随系统）；后续新功能从右向左追加图标。
