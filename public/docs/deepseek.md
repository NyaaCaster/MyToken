# DeepSeek 鉴权密钥获取说明

DeepSeek 官方开放平台提供一个**纯余额查询接口**
`GET https://api.deepseek.com/user/balance`，鉴权用单个 **API Key**（Bearer）。

## 1. 获取 API Key

1. 打开 <https://platform.deepseek.com> 并注册 / 登录。
2. 进入 **API Keys / API 密钥**页面。
3. 点击「创建 API Key（Create new API key）」，生成形如 `sk-xxxxxxxx` 的密钥。
4. **立即复制并保存**（创建后仅完整显示这一次）。
5. 若需要，可在同页为 Key 取名 / 设置配额 / 一键删除（删除后旧 Key 立即失效）。

> ⚠️ API Key 等价于你的账户权限，只保存在本机，**不要**提交到 git 或分享。

## 2. 在 MyToken 中填写

| 输入项 | 示例 | 说明 |
|--------|------|------|
| API Key | `sk-xxxxxxxx` | 必填，见第 1 步 |

填好后点击「认证并启用」即可。MyToken 会读取该 Key 对应账户的余额
（`balance_infos`，多币种下按 CNY 优先 + 正余额挑选）。

## 4. 今日消耗（估算）

DeepSeek 官方**没有**「今日消耗 / token 用量 / 按模型费用」这类可用 API Key 调用的统计接口，
所以模块里的「今日」是 **MyToken 在本机按余额差值估算**出来的，**不是官方账单数字**：

| 项 | 口径 |
|----|------|
| 算法 | 「今天最早一次采样时的余额」− 「当前余额」，并**剔除充值**（按 `topped_up_balance` 增量加回） |
| 日界 | 北京时间 00:00（Asia/Shanghai），与官方账单、模块内价格峰谷口径一致 |
| 采样时机 | 打开页面、手动点刷新、以及每 5 分钟自动刷新（每次查询成功记录一条余额） |
| 展示 | `今日 <金额> <币种> · 估算 · 自 HH:MM 起` —— 起始时刻即当天最早一次采样 |

**为什么只能"估算"、以及什么时候会偏低：**

- 首次采样**之前**发生的消耗（00:00 → 你第一次打开页面）无法观测，永久丢失；
  页面关闭期间的消耗同理。因此**实际消耗可能高于显示值**。
- 页面跨零点一直开着时，零点后第一次自动刷新即近似「00:00 基线」（误差 ≤ 刷新间隔）；
  但浏览器会节流后台标签页，**不保证**零点那次采样一定发生。
- 余额接口只给两位小数（分），日消耗接近 0.01 元时数字会跳、甚至显示 `0.00`；
  日消耗在 0.1 元以上时正常可用。
- **充值**已剔除；但若充值后紧接着又消耗、且两者落在同一次采样间隔内，只能得到净额。
- 赠送余额**过期**会让余额凭空减少（会被算成消耗）。当 15 分钟内余额减少 ≥ 5 元时，
  模块会显示 `⚠ 异常变动` 并给出「**重置基线**」按钮：点击后清空当天样本、以当前余额
  重新起算（随后自动刷新一次）。平台调整、换用大额密钥跑批量任务等情况也可用它兜底。
- 采样数据只存在**本浏览器**的 localStorage（键 `mytoken-balance-log`，保留最近 7 天，
  不包含任何密钥）：手机 / 另一台电脑 / 不同域名的入口各存一份，数字可能不一致；清缓存即丢失。
- 只有「余额」与「静态价格峰谷」来自官方（前者为实时接口，后者为源码内快照）。

## 说明

- DeepSeek 官方**没有**「今日消耗 / token 用量 / 按模型费用」这类可用 API Key
  调用的统计接口，故 MyToken 的 DeepSeek 模块展示的是**实时余额 + 静态价格峰谷 +
  本机估算的今日消耗**（估算口径见上一节）。
- 若返回 401，说明 Key 无效 / 已删除，请回平台重新生成。
