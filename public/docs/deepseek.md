# DeepSeek 鉴权密钥获取说明

DeepSeek 官方开放平台提供一个**纯余额查询接口**
`GET https://api.deepseek.com/user/balance`，鉴权用单个 **API Key**（Bearer）。

## 1. 获取 API Key

1. 打开 <https://platform.deepseek.com> 并注册 / 登录。
2. 进入 **API Keys / API 密钥**页面。
3. 点击「创建 API Key（Create new API key）」，生成形如 `sk-xxxxxxxx` 的密钥。
4. **立即复制并保存**（创建后仅完整显示这一次）。
5. 若需要，可在同页为 Key 取名 / 设置配额 / 一键删除（删除后旧 Key 立即失效）。

> ⚠️ API Key 等价于你的账户权限，只保存在本机，**不要**提交到 git 或分享。

## 2. 在 MyToken 中填写

| 输入项 | 示例 | 说明 |
|--------|------|------|
| API Key | `sk-xxxxxxxx` | 必填，见第 1 步 |

填好后点击「认证并启用」即可。MyToken 会读取该 Key 对应账户的余额
（`balance_infos`，多币种下按 CNY 优先 + 正余额挑选）。

## 3. 价格峰谷（静态展示）

DeepSeek 模块底部会额外展示官方**峰谷定价**。注意：这只是源码内的**静态快照**（不调用
任何接口），随官方调价手动同步。

| 项 | 官方口径 |
|----|---------|
| 高峰时段 | 北京时间**周一至周五 9:00-12:00、14:00-18:00**；其余时段（含周六 / 周日全天）为空闲 |
| 空闲价 | 高峰时段价格的一半（等价：高峰 = 2 × 空闲） |
| 计价单位 / 币种 | 元 / 百万 tokens（CNY）—— 界面上以 `¥` 前缀展示 |

| 模型 | 空闲：缓存命中 / 未命中 / 输出 | 高峰：缓存命中 / 未命中 / 输出 |
|------|------|------|
| `deepseek-v4-flash` | ¥0.02 / ¥1 / ¥4 | ¥0.04 / ¥2 / ¥8 |
| `deepseek-v4-flash-vision-exp`（视觉实验版，与 flash 同价） | ¥0.02 / ¥1 / ¥4 | ¥0.04 / ¥2 / ¥8 |
| `deepseek-v4-pro` | ¥0.15 / ¥4.5 / ¥13.5 | ¥0.30 / ¥9 / ¥27 |

> 数值源：`src/providers/registry.ts` 的 `deepseek.peak`（官方调价时两处一起改，需同步维护）。

  抓取仅返回空壳），故实际可核查载体为公告的**逐字转载**：
  <https://www.dzwww.com/news/yw/202609/t20260909_18097412.htm>（含平台公告截图）、
  <https://m.ithome.com/html/1000692.htm>（含官方 API 用户通知邮件，含 pro 下线路由）。峰谷时段、
  币种与 pro 价依据官方中文定价页 <https://api-docs.deepseek.com/zh-cn/quick_start/pricing>。

## 说明

- DeepSeek 官方**没有**「今日消耗 / token 用量 / 按模型费用」这类可用 API Key
  调用的统计接口，故 MyToken 的 DeepSeek 模块**只展示余额 + 上述静态价格峰谷**。
- 若返回 401，说明 Key 无效 / 已删除，请回平台重新生成。
