# QinyAPI 鉴权密钥获取说明

QinyAPI 基于 **new-api**（`https://love.qinyan.icu`）。它**不使用账号密码登录**，
而是统一用 **访问令牌（Access Token，形如 `sk-xxx`）** 鉴权。在 MyToken 里你需要填
**两个值**：访问令牌 + 用户 ID，缺一不可。

## 1. 获取访问令牌（sk-xxx）

1. 打开 <https://love.qinyan.icu> 并登录。
2. 进入 **个人设置 → 安全设置 → 系统访问令牌**。
3. 点击「生成」，得到形如 `sk-xxxx` 的令牌。
4. 复制并妥善保管（**之后不再完整显示**）。

> ⚠️ 该令牌等价于账号的全部权限，只保存在本机，**不要**提交到 git 或发给任何人。

## 2. 获取用户 ID

用户 ID 就是 `/api/user/self` 返回的 `data.id`（一个数字，如 `10687`），可在网页
**个人中心 / 设置页**看到。

> MyToken 请求时会把 `New-Api-User` 头设为这个 ID，**必须等于令牌所属用户的 ID**，
> 否则返回 401（用户 ID 不匹配）。

## 3. 在 MyToken 中填写

| 输入项 | 示例 | 说明 |
|--------|------|------|
| 访问令牌 | `sk-xxxxxxxxxxxxxxxx` | 必填，见第 1 步 |
| 用户 ID | `10687` | 必填，见第 2 步 |

填好后点击「认证并启用」即可。鉴权通过会显示你的剩余额度（USD，quota ÷ 500000）
与今日/累计花费。
